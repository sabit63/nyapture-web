# 作品起点のレコメンド UI 仕様

状態: 初回実装済み（2026-09-09）。合意事項に加え、実装依頼に基づいて補完した細部を記載する。

## 目的と範囲（確定）

- 閲覧している作品から、関連作品・作者・グループを発見できるようにする。
- 初回実装は作品起点のレコメンドを対象とする。
- 作者・グループを起点とするレコメンド検索、閲覧履歴に基づく個人向け推薦は対象外。
- API 契約は `../openapi.yaml` を参照する。

## 表示と操作（確定）

- ビューアの「関連」導線から専用パネルを開く。
- 検索結果の連続閲覧モードでも同じ導線を表示し、現在の閲覧作品を起点とする。現在作品の切り替えでパネルと候補をリセットし、検索結果の読み込み中はパネルを取り外して通信を停止する。
- 連続閲覧中のパネル内の横スワイプ・ホイール操作は、背景の作品切り替えとして扱わない。作品候補の選択は単独ビューアへ、作者・グループは既存のタグ検索へ遷移する。
- パネルは作品情報・タグ編集とは独立する。
- 閉じると元の作品の同じ読書位置へ戻る。
- パネルは「作品」「作者」「グループ」の3タブで構成し、最初は「作品」を選択する。
- 同じ作品で再度開く場合、取得済み候補と選択タブを保持する。保持期間はその作品のビューア滞在中とする。
- 別作品へ移動したらパネルを閉じる。次に開く際は移動先作品の「作品」タブから開始する。

| 候補 | 表示内容 | 選択後 |
| --- | --- | --- |
| 作品 | 表紙・タイトル・共通タグ | 選んだ作品をビューアで開く |
| 作者 | 名前・作品数・代表タグ | その作者の作品一覧を既存検索画面で開く |
| グループ | 名前・作品数・代表タグ | そのグループの作品一覧を既存検索画面で開く |

- 作者・グループのアイコン領域には、APIが返す `entity.thumbnailBook` の1ページ目を表示する。APIは保存完了・保存先あり・1ページ以上の所属Bookから `uploadedTime` が最新のものを選ぶ。
- 作者・グループの表紙は64×90pxの角丸長方形とし、画像全体が収まるように表示する。丸形の切り抜きやトリミングは行わない。
- `thumbnailBook` の `groupId`・`bookId` を既存の認証付き画像APIに渡す。候補ごとの追加の作品検索は行わない。
- `thumbnailBook` がnull・未提供・識別子なしの場合、および画像取得／表示に失敗した場合は作者・グループのアイコンを表示する。読み込み中は既存のサムネイルスケルトンを表示する。
- パネルの更新でサムネイル対象Bookが変わった場合は画像を再取得する。画像を選んでも従来どおり作者・グループの検索へ遷移する。

- スコアの数値・一致率は表示しない。API の score は一致確率ではない。
- 状態説明文は極力使用せず、アイコンと動きで状態を表現する。
- アイコンの意味はツールチップと読み上げ用ラベルで補う。タッチ操作でも確認可能にする。
- 動きを減らす設定に対応する。

## 取得（確定）

- `GET /api/book/{groupId}/{bookId}/recommendations` を使用する。
- 作品タブはパネルを開いた時、作者・グループタブは初めて選択した時に取得する。
- `targetType` はタブに応じて `Book` / `Artist` / `Group` を指定し、`Both` は使用しない。
- `limit=20`。各タブ最大20件とし、初回実装では追加読み込みを設けない。
- API が返す順序を維持する。
- パネルを閉じる、タブを切り替える、作品を切り替える操作で生成待ちの自動再確認を停止する。

## 状態表示（確定）

| 状態 | UI |
| --- | --- |
| 読み込み中 | カード形状のスケルトンに穏やかな明滅 |
| `pending` / HTTP 202 | 時計アイコンに穏やかな動き |
| `success` で候補0件 | 空状態を示すアイコン |
| `no_features` | 空状態を示すアイコン。読み上げ・補助表示では情報不足と分かるようにする |
| `not_found` / HTTP 404 | 作品に斜線を重ねたアイコン |
| `unavailable` / HTTP 503、通信失敗 | 状態アイコンと再試行アイコンボタン |
| `isStale=true` で候補あり | 候補を表示し、小さな更新待ちアイコンを添える |

- 状態は選択タブ内で表現する。
- 生成待ちは `Retry-After` に従い、パネル表示中の選択タブのみ自動再確認する。
- 自動再確認は最大3回。その後は手動の再試行アイコンボタンに切り替える。
- `Retry-After` が欠落・不正の場合は60秒。正常な値は1秒〜ブラウザのタイマー上限（2,147,483秒）に収める。
- 再確認回数はタブごとに保持し、閉じる・タブ切り替えでリセットしない。再表示時は残りの待ち時間から再開する。手動再試行・更新で回数をリセットする。

## 実装時に補完した細部

- PCは右側の最大520pxのパネル。600px以下では下から開く高さ92dvhのパネル。
- 閉じるアイコン・パネル外のタップ・Escapeで閉じる。背景のスクロールを止め、ネイティブのモーダルでフォーカスを内側に制限する。開くと閉じるボタンへ、閉じると起点のボタンへスクロールなしでフォーカスを戻す。
- タブは左右矢印・Home・Endでも選択できる。
- 候補移動には既存ルーターとタグ検索を利用する。作者・グループは既存条件をリセットしたライブラリ検索となる。元作品へ戻る操作と読書位置の復元は既存ルーターに従い、作品間の移動後はパネルを閉じた初期状態にする。
- 更新アイコンで選択タブを再取得できる。タイトル・タグ編集後も自動再取得は行わず、必要時に更新する。
- 作者・グループの作品数は `entity.totalBookCount`。件数なしの場合は省略する。タグは最大3個、操作なしで表示する。
- 表示名は応答の `tagDisplayNames` を `type` と元の `name` の完全一致で参照する。作者名は `Artists`、グループ名は `Groups`、共通タグ・代表タグは `Tags`。空白以外の `displayName` があれば優先し、未提供・未登録・空白のみの場合は元の名前を表示する。
- 表示名の追加取得は行わない。タグ検索には元の型・名前を使用し、表示名は表示用のメタデータとして渡す。BookのタイトルやAPIのキーは変更しない。
- 表紙は既存の認証付きサムネイルを使用し、欠落時は画像なしアイコン。`book` がなくてもキーが有効ならBook IDをタイトルとして表示し、既存ビューアで個別取得する。閲覧できない作品は既存ビューアの状態表示に従う。
- 遷移キーが欠落した候補・タブと異なる種類・同一キーの重複は除外する。有効候補の順序は維持する。
- パネルを閉じる・タブ変更・作品変更時には取得もキャンセルし、遅れて到着した応答は反映しない。
- 認証失敗は状態アイコンの補助表示で接続設定の確認を案内する。バックエンドの詳細エラー文は直接表示しない。
- ステータスアイコンにはツールチップ・読み上げ名を付け、タップで補足を表示できる。

## 合意済み内容の受け入れ条件

- 関連パネルを開閉しても元作品の読書位置が変わらない。
- 初めて開くと作品タブを取得し、未選択の作者・グループタブを先読みしない。
- 各タブで最大20件を API の順序で表示し、スコア数値を表示しない。
- 同じ作品でパネルを再度開くと、保持中の候補と選択タブを復元する。
- 作品候補を選ぶとその作品が開き、パネルは閉じる。
- 作者・グループ候補を選ぶと、該当タグの作品を既存検索画面で一覧できる。
- 読み込み中・生成待ち・空状態・利用不可などを常設の説明文に依存せず識別でき、補助表示と読み上げで意味を確認できる。
- 生成待ちの自動再確認は最大3回で停止し、パネル非表示・タブ切替・作品切替後に継続しない。
- 古い索引による候補も表示でき、更新待ちであることをアイコンで確認できる。
